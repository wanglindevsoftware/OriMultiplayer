Ori Multiplayer
Author: Wang Lin | Team:DevSoftWare
Network protocol: 34

УСТАНОВКА И ЗАПУСК
1. Закройте Ori. Сохраните резервную копию своего мода и игровых сохранений.
2. Распакуйте СОДЕРЖИМОЕ ZIP в папку с oriwotw.exe. Рядом с игрой должны лежать winhttp.dll, Ori Multiplayer.bat и папка OriMultiplayerMod.
3. При обновлении замените файлы предыдущего Ori Multiplayer. Если winhttp.dll принадлежит другому моду, не заменяйте его без отдельной проверки совместимости.
4. Запустите Ori Multiplayer.bat. Компиляция и прежний архив мода не нужны.
5. В главном меню выберите MULTIPLAYER. В игре: Esc → MULTIPLAYER. F1 больше не используется. Возврат — Esc / Назад.
6. Один игрок создаёт комнату, второй вводит IP хоста и тот же порт. На разных компьютерах 127.0.0.1 не подходит: это адрес текущего компьютера. Порт по умолчанию — TCP 31415. Затем хост выбирает сохранение.
7. На обоих компьютерах используйте одинаковый комплект мода и совместимую версию игры.

ТРЕБОВАНИЯ
Windows x64 и апрельская версия Ori and the Will of the Wisps 2020 года. Ожидаемый размер GameAssembly.dll: 73937920 байт. Файлы самой игры в комплект не входят.
Динамические зависимости включают Microsoft Visual C++ x64 Runtime: MSVCP140.dll, MSVCP140_ATOMIC_WAIT.dll, VCRUNTIME140.dll и VCRUNTIME140_1.dll. При ошибке об отсутствии этих файлов установите Microsoft Visual C++ Redistributable x64. Системные DLL Windows в архив не включены.

НАСТРОЙКИ
Общий мир и общий прогресс включены в исходных настройках мода. Проверено также чтение конфигурации, где эти поля отсутствуют.
Существующий OriMultiplayerMod/multiplayer.json архив НЕ заменяет. Новая конфигурация записывается при сохранении параметров/закрытии страницы. multiplayer.example.json — только образец без личных данных и абсолютных путей.
При ранее отключённой синхронизации откройте Настройки → Восстановить настройки кооператива до подключения.
Настройки синхронизации закреплены на время соединения. Общий прогресс требует общего мира.

ЗВУК
Обычный BAT сохраняет прежний безопасный запуск БЕЗ ЗВУКА, обходящий известный вылет Wwise. Это не исправление звукового движка.
Для отдельной проверки звука доступен запуск "Ori Multiplayer.bat" --sound; прежний вылет может повториться. Параметр disable_audio=true в личной конфигурации продолжает отключать звук.

ДВА ИГРОКА НА ОДНОМ ПК
Необязательный Test Two Players.bat создаёт отдельные профили Host/Client, копии сохранений, копию игрового EXE и ссылку на папку данных; открывает два игровых окна. Он не предназначен для фоновой автоматической проверки.
Collect Multiplayer Logs.bat вручную собирает локальные диагностические журналы; ничего не отправляет в интернет.

ОГРАНИЧЕНИЯ
Это полный комплект мода, а не вся игра и не заявление о безошибочном прохождении всей кампании. Результаты повторной проверки перечислены в RELEASE_NOTES.txt.
Подключайтесь только к доверенным игрокам: сетевой протокол не предусматривает пароль и шифрование.

СОСТАВ
winhttp.dll, Core.dll, Modloader.dll, Multiplayer.dll, modloader_config.json, запуск, необязательный локальный тест двух игроков, инструкции, пример настроек и лицензии.
Сохранений, пользовательского multiplayer.json, дампов, PDB, тестовых журналов, инструментов разработки и файлов шрифтов здесь нет.
Контрольные суммы комплекта находятся в SHA256SUMS.txt.
